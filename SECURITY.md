# Security policy

Please **do not** open a public issue for security problems.

Report them privately through GitHub: on the repository page open **Security → Report a vulnerability**. Include steps to reproduce and the impact you expect. You will get an answer within a week.

These are especially relevant:
- bypassing Slack request verification;
- reading or changing another channel's session;
- exposing someone's dietary needs or ratings;
- injecting content into Slack messages.

Only the latest version on `main` is supported.
